## Adding images

- Fish: add the Commons file name to `tools/fetch_species_art.py` and run `python3 -I tools/fetch_species_art.py`; it skips anything that isn't PD/CC0.
- Stock: only Unsplash/Pexels licence, USFWS/NOAA public domain, or Commons PD/CC0. Add a row here before shipping.
- Then run `node tools/art.mjs` and `node tools/credits.mjs`.
